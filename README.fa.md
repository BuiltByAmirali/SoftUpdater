**بررسی همه‌ی برنامه‌های نصب‌شده‌ی ویندوز از منابع رسمی‌شان — ببینید کدام
برنامه‌ها به‌روزرسانی دارند، در یک نگاه.**

رایگان و متن‌باز (مجوز MIT). بدون تله‌متری، بدون حساب کاربری، بدون تبلیغ.

[**English**](README.md) | **فارسی**

SoftUpdater هر برنامه‌ی نصب‌شده را با **منبع رسمی خودش** مقایسه می‌کند:
GitHub Releases برای برنامه‌های متن‌باز، فیدهای رسمی شرکت‌ها برای
Chrome، Firefox، Edge، VLC، GIMP و ده‌ها برنامه‌ی دیگر؛ سپس نسخه‌ی
نصب‌شده را کنار آخرین نسخه‌ی رسمی نشان می‌دهد و در صورت تمایل، فایل
نصبِ متناسب با معماری ویندوز شما (۶۴ یا ۳۲ بیتی) را **فقط دانلود** می‌کند —
اجرای نصب همیشه با خود شماست.

## امکان‌ها

- تشخیص همه‌ی برنامه‌های نصب‌شده از رجیستری ویندوز + نسخه‌ی ویندوز
  (۷ تا ۱۱) و معماری (۳۲/۶۴ بیتی)
- مقایسه با **منبع رسمی** هر برنامه و وضعیت روشن برای هر ردیف:
  به‌روزرسانی موجود / به‌روز است / نصب‌کننده برای این سیستم نیست / منبعی
  پیدا نشد / خطا در بررسی
- برنامه‌هایی که خودشان به‌روز می‌شوند (Steam، Spotify، Office، آنتی‌ویروس
  و…) برچسب «مدیریت توسط سازنده» می‌گیرند، نه «یافت نشد»
- شش زبان با تغییر زنده: فارسی، عربی، انگلیسی، پرتغالی، فرانسوی و آلمانی —
  و چیدمان واقعی راست‌به‌چپ برای فارسی/عربی
- رابط شیشه‌ای تیره با آیکون‌های برداری دست‌ساز، سایز فونت قابل تنظیم
  (۱۴ تا ۲۰) و نقطه‌ی رنگی وضعیت
- **بدون تله‌متری**: هیچ چیزی از کامپیوتر شما بیرون نمی‌رود؛ فقط به منابع
  رسمی همان برنامه‌ها وصل می‌شود. گزارش‌ها هم داخل همان سیستم می‌مانند.

## دانلود (نسخه‌های رسمی)

نصب‌کننده‌ها فقط از صفحه‌ی
[**Releases**](https://github.com/BuiltByAmirali/SoftUpdater/releases)
همین مخزن منتشر می‌شوند:

| فایل | برای |
|---|---|
| `SoftUpdater-Setup-<version>.exe` | ویندوز ۱۰ / ۱۱ — ۶۴ بیتی |
| `SoftUpdater-Setup-<version>-win32.exe` | ویندوز ۷ SP1 / ۸ / ۸.۱ / ۱۰ / ۱۱ — هر دو معماری |

مطمئن نیستید کدام؟ فایل `-win32` را بگیرید؛ روی همه‌ی این‌ها اجرا می‌شود.

**بازبینی سلامت دانلود:** کنار هر Release یک فایل `SHA256SUMS.txt` هست.
در ویندوز دستور زیر را بزنید و با خط مربوطه مقایسه کنید:

```
certutil -hashfile SoftUpdater-Setup-<version>.exe SHA256
```

> **تنها این مخزن رسمی است.** خود برنامه هم نشانی رسمی را در
> **تنظیمات → درباره** نشان می‌دهد. اگر نسخه‌ای از جای دیگری لینک مخزن،
> ناشر یا صفحه‌ی حمایتی متفاوتی داشت، رسمی نیست.

## اجرا از سورس

روی `run.bat` دابل‌کلیک کنید (یا `python run.py`). یک بار پایتون ۳.۱۰+
لازم است؛ خود اسکریپت محیط مجازی می‌سازد و کتابخانه‌ها را نصب می‌کند.

## ساخت

- **exe تک‌فایلی قابل‌حمل:** `build.bat`
- **نصب‌کننده‌ی رسمی ۶۴ بیتی:** `build_installer.bat`
- **نصب‌کننده‌ی وین۷ / ۳۲ بیتی:** `build_installer32.bat`
- ** checksums برای Release:** بعد از ساخت، `build\make_checksums.bat`
